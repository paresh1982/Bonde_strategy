# Sample & Synthetic Data Directory (Stage 0)

This directory contains synthetic and sample datasets used for Stage 0 deterministic engine verification.

## Disclaimer
Synthetic test data is engineered strictly to verify software mechanics, edge cases, and state machine causality.
**Synthetic data does NOT represent historical market performance or trading edge evidence.**

## Stage 1 Prerequisite
In Stage 1, this directory will be augmented with historical 1-minute bars and point-in-time corporate earnings data from institutional data vendors.
